### 🚀 About Me

I'm a full-stack developer interested in building reliable applications, AI-powered tools, workflow automation, and thoughtful user experiences.

My background in systems analysis and quality assurance shapes how I approach development: understand the problem, design for maintainability, test carefully, and keep the user experience clear.

- 🔭 Exploring full-stack architecture, AI-assisted tools, and local-first software
- 🧠 Interested in systems analysis, database design, automation, and application security
- 🎨 Building accessible interfaces and reusable design systems
- 🧪 Focused on testing, performance, documentation, and maintainable code
- 💬 Ask me about TypeScript, Next.js, PostgreSQL, WordPress, or development workflows

---

### 🧠 How I Build

> *Code should be understandable, maintainable, and built around a real problem.*

- **Clarity over complexity:** Prefer solutions that are easy to understand and maintain.
- **Systems thinking:** Consider how data, users, services, and processes work together.
- **Quality throughout:** Treat testing, accessibility, security, and documentation as part of development.
- **Practical automation:** Use AI and automation where they produce clear, reliable value.
- **Design with purpose:** Build interfaces that are both functional and pleasant to use.
